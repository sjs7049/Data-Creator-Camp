# 위성 이미지 기반 굴뚝 탐지·높이 추정

> 2025 데이터 크리에이터 캠프 대학부 · 팀 인하오남매(5인) · 2025.08–10

위성 이미지에서 대기오염 배출원인 굴뚝을 찾고(Mission 1), 그 높이를 미터 단위로 추정(Mission 2)한 프로젝트입니다. 대회는 산업단지 영역 분할(Mission 3)까지 세 미션으로 구성되었고, 이 저장소에는 Mission 1·2 노트북이 들어 있습니다.

## 결과 (독립 테스트셋 기준)

| 미션 | 모델 | 테스트 데이터 | 결과 |
|---|---|---|---|
| Mission 1 · 굴뚝 탐지 | YOLOv8m | 이미지 1,006장 · 굴뚝 1,322개 | mAP50 **0.988**, mAP50-95 0.869, Precision 0.969, Recall 0.983 |
| Mission 2 · 높이 추정 | EfficientNet-B0 (RGB + 마스크 4채널) | 굴뚝 1,323개 | RMSE **6.42m**, MAE 4.11m, R² 0.983 |

## 내 역할

- **Mission 1 전담:** 라벨 변환, 데이터 분할, 모델 비교·튜닝, 추론과 평가까지 전 과정을 수행했습니다.
- **Mission 2 지원:** Mission 1을 마친 뒤, 검증 RMSE가 20m대에 머물던 높이 추정에 합류했습니다. 전처리부터 다시 점검해 **굴뚝 위치 마스크를 입력 채널로 추가**하는 방식을 비교 실험으로 찾았고, 고층 오차를 줄이는 고도화 방안을 정리해 팀원과 실험을 나눠 진행했습니다.

## Mission 1 · 굴뚝 위치 탐지

**데이터:** AI Hub ‘대기오염 배출원 공간 분포 데이터셋’(Kompsat-3/3A 위성 이미지). 학습 이미지 8,052장, 굴뚝 10,619개.

1. **라벨 변환:** 원본 라벨이 VIA JSON 형식이고 Roboflow가 이를 지원하지 않아, 사각형 좌표를 YOLO 형식(txt)으로 바꾸는 변환 코드를 직접 작성했습니다.
2. **데이터 분할:** 파일명 순서대로 나누면 정보 누수가 생길 수 있어, 학습/검증을 **9:1 무작위 분할**(시드 42)했습니다.
3. **모델 크기 비교:** 같은 조건(20 epoch, 입력 640px)에서 세 크기를 비교한 뒤, 대회 지표인 mAP50이 가장 높은 m을 골랐습니다.

   | 모델 | 검증 mAP50 |
   |---|---|
   | YOLOv8n | 0.982 |
   | YOLOv8s | 0.986 |
   | YOLOv8m | **0.987** |

4. **튜닝:** 입력 크기를 800px로 키우고 40 epoch으로 늘려 학습했습니다. 추론 설정은 대회 규정(conf 0.25, IoU 0.50)을 따랐습니다.

## Mission 2 · 굴뚝 높이 추정

**접근:** 이미지 한 장에 굴뚝이 여러 개 있을 수 있어, 원본 RGB만 넣으면 모델이 어느 굴뚝의 높이를 맞혀야 하는지 알기 어렵습니다. 그래서 대상 굴뚝의 폴리곤으로 마스크를 만들어 **RGB + 마스크 4채널**로 입력했습니다.

**높이 분포 불균형 대응**
- 높이를 log1p로 변환해 정규화하고, 높이 구간별 층화 분할로 학습/검증 분포를 맞췄습니다.
- 고층 굴뚝 샘플이 적어 WeightedRandomSampler로 학습 시 노출 빈도를 보정했습니다.
- 상위 높이 구간에 가중치를 더 주는 Huber 기반 손실(Height-aware Loss)을 사용했습니다.
- 예측 상위 20% 구간에만 선형 보정(calibration)을 적용했습니다.

**검증 RMSE 변화 (검증셋 기준)**

| 단계 | 변경 | 검증 RMSE |
|---|---|---|
| 기준 | RGB 이미지만 입력 | 23.50m |
| 입력 개선 | RGB + 마스크 (9가지 모델·입력 조합 중 최고) | 11.39m |
| 학습 확장 | 100 epoch 학습 | 7.71m |
| 손실·보정 | Height-aware Loss + 상위 구간 보정 | 6.93m |
| 최종 | 가중 강도 조정 | **6.82m** (R² 0.981) |

마스크 입력만으로 검증 RMSE가 약 52% 줄었습니다((23.50 − 11.39) / 23.50).

## 평가 원칙

- **검증셋과 테스트셋 수치를 섞지 않았습니다.** 위 표의 단계별 수치는 모두 검증셋 기준이고, 최종 성능은 학습에 쓰지 않은 독립 테스트셋(VS_KS)에서 따로 측정했습니다.
- **보정 파라미터는 검증셋에서만 추정**하고 테스트셋에는 적용만 했습니다. 테스트셋으로 보정을 맞추면 성능이 실제보다 좋게 보이기 때문입니다.
